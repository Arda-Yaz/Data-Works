# Unaided monthly fulfillment observation

Status: **not performed**. This sheet is a protocol, not customer evidence.
Use permissioned exports and the dashboard's agreed input contract. Attribute any
recorded data and retain it according to the operator's permission.

Before observation, record operator role, date, recurring problem confirmation,
current preparation steps, export provenance, two consecutive reporting months,
and the dashboard fields/types/status/date/CSV-text requirements. Record the
DataWorks commit, installed packages, host, and agreed policy for each decision.
Keep synthetic fixtures separate from the operator's own files.

Ask the analyst to complete these tasks without directing their button choices:

1. Prepare the first month's file and explain what each total counts. Review
   quarantine, verify source references, and compare agreed dashboard totals.
2. Retain the plan and project, close the session, reopen the project, and prepare
   the second month's export using the unchanged plan.
3. On a separately labeled test copy, recover from an incompatible column,
   an unmapped status, and conflicting duplicate records. Identify which report
   is still downloadable after an unsuccessful attempt.
4. Inspect a rejection reason and explain whether the filter changes execution,
   report totals, or downloaded rows. Undo a change when a checkpoint is retained.
5. Prepare a project with and without undo, retain the actual download, and reopen
   it. Explain which state is retained and which history is unavailable.

For each task, record completion, active preparation minutes, elapsed minutes,
manual decisions, corrections, assistance required, and the analyst's explanation
of source/plan/result/archive state. Record mistakes and recovery paths without
silently assisting. Keyboard and screen-reader observations belong here too;
automated AppTest cannot establish those accessibility outcomes.

The Phase 1 proposed value gate remains at least 50% lower active preparation
time on each export with zero unexplained line/order-count differences. Report
unaided task completion and each recovery observation separately; do not invent a
new numeric usability threshold after observing results. A synthetic walkthrough
does not establish demand or satisfy this gate. One operator does not establish
market fit. An independent person must still reproduce the release package in
Phase 6.
